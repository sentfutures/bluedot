# Sentient Futures fork of BlueDot

Read [`SENTIENT-FUTURES.md`](../SENTIENT-FUTURES.md) before changing anything. This repo is public
and AGPL-licensed. In short:

- Never add code from Kairos's repo, `sentfutures/kairos-shared` or `sentfutures/sf-dashboard`:
  it is confidential and must not be published.
- Never copy code from here into a private Sentient Futures repo. Connect over HTTP or Airtable
  instead.
- Never commit secrets, Airtable IDs or participant data. Use environment variables.
- Every deployed app needs a visible "Source code" link to this repo.
- Log each change we make, with its date, in the "Our changes" table in `SENTIENT-FUTURES.md`.
